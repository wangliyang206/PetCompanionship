## 0. 项目是什么（30 秒背景）

3D 宠物陪伴休闲手游。玩家获得灵卵 → 孵化 → 抚育成长 → 解锁行为动画 → 收集图鉴 → 桌面小组件陪伴。宠物以《西游记》"五虫"为世界观根基，稀有度在破壳瞬间揭晓（事先不可知），长期收集目标为多层级图鉴。

**产品主轴（核心体验链）**：`寻蛋 → 孵化 → 抚育成长 → 解锁行为动画 → 图鉴 → 桌面小组件陪伴`

**三条设计铁律**（任何功能设计冲突时以此裁决）：
1. 陪伴感是真实的：宠物有行为、有记忆、会主动出现；
2. 低负罪感：忘记照顾无数值惩罚，只有失落的行为表达，永远可修复；
3. 轻量短回合：每次打开 3~5 分钟完成一轮循环。

## 4. 数据模型（实现时照此定义，不得私自改字段）

### 4.1 枚举
```ts
enum Xi { Mao, Yu, Lin, Jie, Luo }          // 五系：毛/羽/鳞/介/倮
enum Rarity { Common, Rare, Epic, Legend }  // 普通/稀有/史诗/传说
enum Stage { Egg, Baby, Adult, Final }      // 卵/幼崽/成体/完全体
enum Behavior { Happy, Calm, Sad, Expect }  // 开心/平静/失落/期待（行为化状态，无数值条）
enum EggSource { Starter, Daily, Explore, Trial } // 新手/保底/探索/终局试炼
enum MemoryEventType { Feeding, Playing, Pet, ExploreReturn, Milestone, Away, MissYou } // 记忆事件（含抚摸 Pet）
enum EggPattern { Plain, Swirl, Dots, Zigzag, Star } // 蛋纹路（纯视觉，与稀有度无关）
```
> 持久化说明：实现为**字符串枚举**（如 `Xi.Mao = 'mao'`），存档中以字符串字面量落盘，可读性更好；跨版本迁移按字符串处理。

### 4.2 存档结构（GameSave，JSON 持久化，sys.localStorage）
```ts
interface SaveData {
  version: number;               // 存档版本，结构变更时 +1 并写迁移（当前 2）
  createdAt: number;             // 首次启动时间戳(ms)
  lastSeenTs: number;            // 上次退出时间戳（离线结算用）
  food: number;                  // 食物库存
  stardust: number;              // 星尘（重复转化/互动奖励）
  dailyGiftTs: number;           // 上次每日赠送时间
  eggPityTs: number;             // 上次 3 天保底蛋发放时间
  eggs: EggState[];              // 全部蛋（含孵化中与窝边排队）
  pets: PetState[];              // 全部已孵化宠物
  activePetId: string;           // 当前主宠（同一时间只有主宠在场；''=空窝）
  memory: MemoryEvent[];         // 记忆系统关键事件（见 4.4）
  collectionFlags: Record<string, boolean>; // 图鉴/奖励/版图解锁标记（纯布尔）
  exploreStates: Record<string, ExploreState>; // 各宠物探索状态（key=petId）
  notificationPrefs: { dailyMissYou: boolean }; // "今日想见你"通知开关
}
interface EggState {
  id: string; speciesId: string;
  hatchesAt: number;             // 孵化完成时间戳；排队中为 0
  source: EggSource;
  touchReduceMin: number;        // 抚摸累计缩短分钟数
  incubating: boolean;           // true=孵化中；false=窝边排队等待孵化位
  pattern: EggPattern;           // 蛋壳纹路（纯视觉，与稀有度无关）
}
interface ExploreState { startTs: number; endTs: number; returned: boolean } // 派出/预计归来/已结算
interface PetState {
  id: string; speciesId: string;
  stage: Stage;
  stageEnteredTs: number;        // 进入当前阶段的时间
  companionship: number;         // 陪伴值（加速成长用，见 GameConfig）
  lastInteractTs: number;        // 上次互动时间
  missYouTs: number;             // 上次被"今日想见你"选中的日期
}
interface MemoryEvent { ts: number; type: string; payload?: string } // type: Feeding/Playing/Pet/ExploreReturn/Milestone/Away/MissYou
```

  anims: Partial<Record<Stage, string[]>>; // 各阶段可用动画（解锁映射）
  themeColor: string;
  signature: string;             // 完全体标志性动作动画名
  lines: { happy: string[]; sad: string[]; away: string[]; feed: string[]; pet: string[] }; // 现代萌系台词

### 4.4 MVP 范围（14 项，与 PRD 一致）
毛虫系3只四阶段成长线；行为化状态+记忆+见面回应；手势互动（抚摸/喂食/逗玩/长按破壳）；探索带回（食物/虫卵/见闻）；重要事件通知；图鉴+主宠切换；本地存档；食物经济；行为动画阶段解锁；桌面小组件；稀有度破壳揭晓；成长可爱进度（蛋壳裂纹/爪印）；重复处理B+A；反歧视机制（今日想见你+双倍星尘+系集齐奖励+失落可视化）。

**明确不做**：社交、商业化、装扮、悬浮窗/动态壁纸、四灵四凶山海经（仅定义层，不实装）、微信小游戏。

### 4.5 Android 原生集成（M4-T17 / T18）

- **原生源码真相源**：`native/android/`（仅 Java 与 res，不含 Gradle 工程）
- **注入脚本**：Creator 完成一次 Android 构建后执行 `node tools/inject-android.js`
  1. 复制 Java/res 到 Creator 的 Android 原生工程（Gradle 中 `:app` 模块 projectDir 指向 `native/engine/android`）：
     - Java：`native/android/app/src/main/java` → `native/engine/android/app/src`（8 个 Java 文件）
     - res：`native/android/app/src/main/res` → `native/engine/android/app/res`（布局/配置/drawable/strings，6 个文件）
  2. 向 `native/engine/android/app/AndroidManifest.xml` 注入权限（POST_NOTIFICATIONS、RECEIVE_BOOT_COMPLETED、SCHEDULE_EXACT_ALARM、WAKE_LOCK）与 3 个 receiver
  3. 在 `native/engine/android/app/src/com/cocos/game/AppActivity.java` 的 `onCreate` 里 `super.onCreate()` 之后注入 `BridgeContext.init(this)` 与 `PetNotificationBridge.onContextReady(this)`（脚本幂等，可重复执行）
- **JSB 入口**：
  - `com.petcomp.game.notify.PetNotificationBridge`：`schedule(int, String, String, String)` / `cancel(int)` / `cancelAll()` / `hasPermission()` / `requestPermission()`
  - `com.petcomp.game.widget.PetWidgetStore.update(String name, String status)`
- **TS 入口**：`NotifierBridge.attach(save)` / `WidgetBridge.attach(save)`，由 `GameRoot.bootstrap()` 统一注册；通知与组件文案一律不含稀有度
  - `Main.scene` 目前没有挂任何入口组件，因此 `GameRoot.ts` 在模块加载时自举：`director.once(Director.EVENT_AFTER_SCENE_LAUNCH)` → `bootstrap()`，`game.EVENT_HIDE` → `flush()`，`game.EVENT_SHOW` → `resume()`；`bootstrap()` 自带幂等守卫，后续挂入口组件重复调用也安全
- **打包前必须就绪（全部装 E 盘）**：JDK 17、Android SDK（platform-tools + platform 34 + build-tools 36.0.0）、NDK r23c、adb 设备授权、Gradle 8.11.1（AGP 8.10.1 要求）
- **本机现状（2026-11-05 实测）**：
  - JDK 17：`JBR-17.0.14`（`java -version` 可用）
  - Android SDK：`C:\Users\Administrator\AppData\Local\Android\Sdk`（platforms 28~35、build-tools 30~36、platform-tools/adb 已就绪；**注：在 C 盘，与"软件装 E 盘"约定冲突，后续可迁到 `E:\tools\android-sdk`**）
  - NDK：`E:\tools\android-ndk\r23c`（r23c = 23.2.8568313，Creator 3.8 官方推荐版本）；本机在 `C:\...\Android\Sdk\ndk\23.2.8568313` 建了目录联接指向它，满足 AGP `ndkVersion` 查找
  - build-tools：`36.0.0`；compileSdk / targetSdk = 34，minSdk = 21（Creator 模板默认）
  - Gradle：8.11.1（AGP 8.10.1 要求；官方源下载会卡住，改用腾讯镜像 `https://mirrors.cloud.tencent.com/gradle/gradle-8.11.1-bin.zip`，解压到 `%USERPROFILE%\.gradle\wrapper\dists\gradle-8.11.1-bin\...` 并放 `.ok`）
  - 已连接真机：`adb devices` 可见 2 台（`2663CAS60353` A8S/Android 10 **仅 armeabi-v7a**、`f7d2f9ae`）
  - 本机限制：Shell 直接启动的 GUI/JVM 进程写 E 盘会被 `EPERM / 拒绝访问` 拦截，**Creator 与 Gradle 必须用 WMI（`Invoke-CimMethod Win32_Process Create`）派生的进程运行**
- **构建步骤**：
  1. 原生环境：`%USERPROFILE%\.CocosCreator\profiles\v2\packages\program.json` 与工程内 `profiles/v2/packages/program.json` 写入 `androidSDK.path` / `androidNDK.path`
  2. CLI 构建（需要 `configPath` JSON，内联 `platform=android;...` 不支持嵌套的 `packages.android`）：
     `CocosCreator.exe --project E:\git\PetCompanionship --build "configPath=<build-android.json>"`（退出码 **36 = 成功**，34 = 构建失败，32 = 参数非法）
     - `packages.android`：`packageName: com.petcomp.game`、竖屏、**`apiLevel: 34`（必须是数字，写 `"android-34"` 会让 gradle.properties 生成 `NaN`）**、`appABIs: ["arm64-v8a","armeabi-v7a"]`、`useDebugKeystore: true`
  3. `node tools/inject-android.js`（每次重新构建都要执行一次，脚本幂等；`native/engine/` 是 Creator 生成的目录，不入库）
  4. 在 `build/android/proj` 执行 `gradlew.bat assembleDebug --no-daemon`（首次含 704 个 C++ 目标，约 3~4 分钟；之后增量约 15 秒）
  5. `adb install -r build/android/proj/build/PetCompanionship/outputs/apk/debug/PetCompanionship-debug.apk`
  6. 真机验收（T17/T18）：
     - 启动后 logcat 出现 `JS: [GameRoot] 启动编排完成`（脚本自举生效）
     - `adb shell "dumpsys alarm | grep -i petcomp"` 可见 `RTC_WAKEUP ... NotificationAlarmReceiver`（离线结算产生的蛋已排闹钟）
     - `adb shell "run-as com.petcomp.game cat shared_prefs/pet_widget.xml"` 可见 `name` / `status`（小组件文案已推送）
     - 桌面长按 → 小组件 → 添加「小窝」并点击，可拉起 App
     - 注意：`adb install -r` 不会重新注册 AppWidgetProvider，需 `adb uninstall` 后再安装才能看到 provider 重新登记

**关键产品规则（写代码时必须遵守）**：
- 蛋的外观/纹路/孵化时长与稀有度无关，任何 UI/通知/日志**不得泄露蛋内物种与稀有度**；
- B 阶段（图鉴未集齐）：产蛋时只从**未拥有种类**抽取；A 阶段（集齐后）：重复孵化转星尘；
- 宠物无死亡、无衰减惩罚；离线只用行为表达（Sad），重新照顾数分钟内回暖；
- 稀有度零优势：成长/互动/探索收益不随稀有度变化；
- 行为动画按 Stage 解锁：Egg(呼吸/摇摆/抚摸颤动) → Baby(互动基础组) → Adult(探索+新动作) → Final(标志性大招)。
