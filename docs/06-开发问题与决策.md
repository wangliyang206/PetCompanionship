- [x] **D9 `adb install -r` 不会重新注册 AppWidgetProvider**：覆盖安装后 `dumpsys appwidget` 看不到 provider，`adb uninstall` 后再安装才重新登记 → 验收小组件前需全新安装。

## 2026-11-06 · 新决策 D32/D33/D34（孵化场景 + 破壳演出）

- **D32**（T25）：2D 灵卵叠加层覆盖 3D 灰圆方案。`GameUI.updateEggOverlay` 每帧把 PetAnchor 世界坐标投影到 UI 坐标（`SceneAnchors.worldToUi`），用 `EggArt.createEggNode(eggId, style)` 创建 2D 灵卵挂在 `this._eggOverlay`（UI_2D 层压在 3D 场景之上），按 eggId 哈希选稳定样式。同一枚蛋只建一次（`_lastEggId` 防重建）。软垫造型（`drawEggPad`）同理挂 UI_2D 层在 HOME 投影处绘制，盖住 3D Nest 椭球。倒计时条（`_eggPill`）也从底部固定位置改为世界→UI 投影后设在蛋下方 y-100。**没有新增资源，全部纯 Graphics + 投影**。
- **D33**（T27）：破壳演出架构。`GameUI.updateHold` 追踪 ready 蛋长按进度（累积到 900ms 触发），实时绘制裂纹进度反馈（`drawHatchCrack`）；`runHatchPerformance` 串行演出：shake → flash 白光 → pieces 蛋壳飞散 → hatchEgg（此时才真正破壳，PetView 会收到 `EggBrokenShell` 事件异步刷新模型）→ celebrate 弹跳 → 星尘粒子 → DialogBubble.show('我出来啦！')。演出全部用**纯 Graphics + tween**，零贴图依赖，可在 web / Android 全端流畅运行。稀有度放射光（`doBeam`）从蛋 UI 位置向外扩散（8 道光柱 + 中心光球 + 白芯），Common 档因 `RARITY_FX.Common=null` 自然跳过但基础演出完整。
- **D34**（T27）：离线孵化补演出实现。核心铁律：**`EggSystem.hatchEgg` 只在 `GameUI.hatch()` 中被调，`hatch()` 又只在 `runHatchPerformance` 内被调**。离线结算（`GameRoot.resume` 里调 `promoteQueuedEggs`）只做排队补位，从不触碰 ready 蛋；`findReadyEggs` 找到的蛋在 UI 层只用来更新 Pill 文字和提示光环。这意味着：**离线期间任何到点的蛋都保持"ready 待孵"状态，必须由玩家长按触发完整破壳演出**——严格遵守 PRD 2.2.4 要求，禁止静默换模型。
