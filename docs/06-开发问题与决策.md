- [x] **D9 `adb install -r` 不会重新注册 AppWidgetProvider**：覆盖安装后 `dumpsys appwidget` 看不到 provider，`adb uninstall` 后再安装才重新登记 → 验收小组件前需全新安装。

### 本轮新增决策（2026-11-06）

- [x] **D11 真机 GL_OUT_OF_MEMORY 崩溃 → PetView 只加载 Mesh + 纯色材质**：美术 GLB 内嵌 3~4 张 4096×4096 贴图（单张 RGBA 64MB），Mali-T820 上传时 `glTexSubImage2D ... - [x] **D12 自建材质必须校验 `passes.length > 0`**：真机上 `EffectAsset.get('builtin-standard')` 返回 null，`new Material().initialize()` 得到 0 passes，赋给 `MeshRenderer` 会在原生 `Model::setSubModelMaterial → SubModel::setPasses → IntrusivePtr<Pass>::operator->` 空指针崩溃（SIGSEGV）。`PetView.makeMaterial` 改为按候选 effect（builtin-unlit → builtin-standard）尝试，passes 为 0 时保留渲染器默认材质。

- [x] **D14 表现层坐标系固定 720×1280**：项目未设置设计分辨率（真机 `view.getVisibleSize()` 为 1280×2275），UI 常量按 720 设计稿书写 → `SceneSetup.setup()` 先 `view.setDesignResolutionSize(720, 1280, FIXED_HEIGHT)` 再建 Canvas/UI 相机。
