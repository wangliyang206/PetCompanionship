## 1. 技术选型

| 项 | 选型 | 理由 |
|---|---|---|
| 引擎 | **Cocos Creator 3.8.x** | 完整 3D + 动画状态机；一键导出 Android；原生支持导出微信小游戏（为二期铺路） |
| 语言 | TypeScript（全栈单语言） | 项目规模适中，类型安全 |
| UI | Cocos UI 系统 | — |
| 3D 资产 | Blender 建模 → glTF/FBX 导入 | 四阶段 × 3 只 = 12 个模型（卵×1 可复用变体） |
| 通知 | Android 原生桥接（JSB / Android 插件） | 本地定时通知（重要事件） |
| 存档 | JSON 本地存档（`sys.localStorage` + 文件） | MVP 本地存档 |
| 音频 | 轻量 BGM + 宠物叫声（呼噜/咀嚼） | 治愈系音频 |

## 2. 架构设计（模块划分）

```
PetCompanionship/
├── docs/                        # 产品与开发文档
├── assets/
│   ├── scenes/                  # 主场景（小窝）
│   ├── scripts/
│   │   ├── core/                # 游戏状态与存档
│   │   │   ├── GameSave.ts      # 本地存档读写
│   │   │   ├── TimeService.ts   # 离线时间计算、成长计时
│   │   │   └── GameConfig.ts    # 数值配置（节奏、掉落概率）
│   │   ├── pet/
│   │   │   ├── PetData.ts       # 宠物定义（五虫表、成长阶段）
│   │   │   ├── PetBehavior.ts   # 行为化状态机（开心/失落/待机/互动）
│   │   │   ├── PetMemory.ts     # 记忆系统（事件记录与台词选择）
│   │   │   └── PetView.ts       # 3D 渲染挂载、动画驱动
│   │   ├── interaction/
│   │   │   ├── TouchPet.ts      # 抚摸手势（划动检测）
│   │   │   ├── DragFeed.ts      # 拖拽喂食
│   │   │   └── PokePlay.ts      # 点击逗玩、长按破壳
│   │   ├── explore/
│   │   │   └── ExploreSystem.ts # 派出/归来/奖励结算（食物/虫卵/见闻）
│   │   ├── notify/
│   │   │   └── NotifierBridge.ts# Android 原生通知桥接（重要事件）
│   │   └── ui/
│   │       ├── CollectionUI.ts  # 图鉴 + 主宠切换
│   │       ├── DialogBubble.ts  # 宠物台词气泡
│   │       └── HUD.ts           # 食物库存、探索入口
│   └── resources/               # 模型、动画、音频、图集
```

### 关键机制说明
- **行为状态机**：`PetBehavior` 输入（离线时长、最近事件、当日互动量）→ 输出行为标签（开心/平静/失落/期待），驱动动画与台词；无数值条。
- **动画解锁**：`GameConfig` 维护"阶段 → 可用动画集合"映射表，`PetView` 按当前阶段过滤动画，进阶时播放解锁演出。
- **记忆**：`PetMemory` 只存"关键事件列表"（最后上线时间、最近 3 次喂食、探索记录、里程碑），台词按事件优先级选取。
- **成长**：真实时间流逝 + 陪伴值加速；离线期间由 `TimeService` 在下次启动时统一结算（探索归来、阶段进化、待通知事件）。
- **通知**：派出探索/孵化时注册一条本地定时通知；启动时清掉已过期的通知。
- **桌面小组件**：Android AppWidget（原生层），由 App 在状态变化时（进阶/派出探索/归来）推送更新：宠物缩略形象 + 状态文案，点击拉起 App。

## 4. 风险与对策
| 风险 | 对策 |
|---|---|
| 12 个 3D 模型+动画量偏大 | M1 用占位资源先验证逻辑；动画复用一套骨骼 |
| 本地通知在部分 Android 机型受限 | 权限引导 + 降级为启动时结算提示 |
| 桌面小组件各厂商刷新策略不一 | 小组件内容轻量化（静态图+文案），更新由 App 内事件驱动，不依赖后台常驻 |
| 行为化状态"读不懂" | 台词气泡兜底：行为 + 台词双通道表达 |
| 离线结算时序 bug（改系统时间等） | 结算基于时间戳单调校验，异常时按保守值处理 |
