## 1. 产品概述

### 1.1 一句话定位
一款 3D 宠物陪伴休闲手游：玩家以"五虫"幻兽为伴，通过照顾、互动、探索与被记住，获得低成本、低负罪感的情感陪伴。

### 1.2 目标用户
- 独居年轻上班族/学生，时间碎片化。
- 需求：低成本的情感寄托；讨厌重度肝氪；喜欢"回来发现它在等我"的感觉。

### 1.3 发布平台
- **首版**：Android App（Cocos Creator 导出）。
- **后期**：微信小游戏/小程序（技术栈已预留该能力）。

### 1.4 设计支柱（所有功能以此为判据）
1. **陪伴感是真实的**——宠物有行为、有记忆、会主动出现；
2. **低负罪感**——忘记照顾没有数值惩罚，只有失落的行为表达；
3. **轻量短回合**——每次打开 3~5 分钟完成一轮循环，随来随走。

### 1.5 核心体验链（产品主轴，2026-11-05 确认）
```
寻蛋 → 孵化 → 抚育成长 → 解锁行为动画 → 图鉴 → 桌面小组件陪伴
```

## 2. 核心系统设计

### 2.1 宠物体系：五虫（世界观核心）
以《西游记》佛祖所言"五虫"为宠物分类根基：

| 系 | 古义 | 原型方向 | 一期 | 最终 |
|---|---|---|---|---|
| 毛虫 | 兽类 | 毛茸茸走兽 | ✅ 首发系（3 只分支） | 5 只 |
| 羽虫 | 禽鸟类 | 飞羽 | 3 只 | 5 只 |
| 鳞虫 | 鱼龙类 | 鳞光水族 | 3 只 | 5 只 |
| 介虫 | 龟甲类 | 甲壳 | 3 只 | 5 只 |
| 倮虫 | 裸体类（人为长） | 通灵幻兽 | 3 只 | 5 只 |

- 规模路线：一期 5 系 × 3 只 = 15 只 → 后期每系扩展至 5 只 = **最终 25 只**，图鉴收集驱动；
- **收集版图四层结构**（远期规划）：五虫 25 → +混世四猴 29 → +四灵（麟/凤/灵龟/神龙）33 → +四神兽（青龙/白虎/朱雀/玄武）37 → +上古四凶（混沌/穷奇/梼杌/饕餮，被陪伴感化的心象凶兽）41 → 山海经异兽**开放式图鉴池**（无上限，随版本新增）；每层解锁要求上一层全部完全体（详见《03-宠物形象设定文档.md》第 6 节）；
- **终局彩蛋【混世四猴】**：五虫 25 只全部完全体后解锁的隐藏独立池（4 只，不在五虫体系内，详见《03-宠物形象设定文档.md》第 5 节）——终局目标 + 反稀有度歧视的终极锚；
- MVP 只做毛虫系 3 只（详细形象见《03-宠物形象设定文档.md》）。

### 2.2 成长阶段（四阶段）
```
蛋/卵 → 幼崽 → 成体 → 完全体
```
| 阶段 | 时长（中等节奏） | 解锁内容 |
|---|---|---|
| 卵 | 按蛋类型（见 2.2.1） | 呼吸鼓动、左右轻摇、可抚摸加速；孵化需长按破壳（仪式感时刻） |
| 幼崽 | 1~2 天 | 基础互动反馈（被摸/被喂/被逗），动作稚拙，反馈最强 |
| 成体 | 3~7 天 | 外出探索 + 新动作组 |
| 完全体 | — | 标志性大招动作，图鉴点亮 |

- **行为动画按成长阶段逐步解锁**，每个阶段都有"它学会新东西了"的惊喜（映射表见《03-宠物形象设定文档.md》）。

#### 2.2.1 孵化时长基准（存于 GameConfig.ts，可调参）
| 蛋类型 | 孵化时长 |
|---|---|
| 初始蛋（新手三选一） | 15 分钟（抚摸加速至最快约 5 分钟，首次会话内破壳） |
| 所有非初始虫卵（统一，**不暴露稀有度**） | 4 小时（日常抚摸可小幅加速，上下班间隙即可完成一轮） |

- 蛋的外观统一，仅随机纹路花样，**纹路与稀有度无关**——孵化前不能让玩家猜到成色；
- **稀有度在破壳演出瞬间揭晓**（见 2.14 稀有度系统）。

#### 2.2.2 第一个蛋：新手三选一认领仪式
1. 首次启动 → 空窝轻引导；
2. 三枚灵卵**从五系中随机抽取**（不同系各一枚，蛋壳纹路不同）**三选一**；
3. 拖拽放到窝内软垫 → 孵化倒计时开始；
4. 等待中引导摸蛋加速（首次互动教学）；
5. 三选一只决定"第一只"，未获得的宠物后续仍可通过探索/每日赠送获得；
6. MVP 降级：仅实装毛虫系时从毛虫系 3 只随机展示，逻辑按"随机抽系"实现。

- **互动加速成长**：抚摸/喂食/逗玩积累"陪伴值"，缩短成长等待。
- 完全体后宠物继续陪伴，收集下一只是长期动力。

### 2.3 状态系统：行为化表达（无数值条惩罚）
- 宠物没有可见的数值条，也**不会因为被忽略而死亡或严重惩罚**。
- 状态通过行为表达：
  - 状态好：主动蹭你、叼玩具给你、蹦跳、眯眼呼噜；
  - 状态失落：蹲坐无精打采、慢半拍回应、抬头看你又低头；
  - 回应"你很久没来"："你去哪儿了呀，我一直蹲在这里等你……"
- 重新照顾后数分钟内行为回暖，**永远可以修复关系**。

### 2.4 记忆系统
- 宠物记住关键事件：距上次上线的时长、喂过什么、玩过什么、探索带回了什么。
- 见面时主动提及（现代萌系口语）：
  - 离线 3 天："你三天没来啦，我把小饼干都留到过期了呜。"
  - 记住偏好："今天又是小鱼干！我就知道你记得我爱吃这个。"

### 2.5 主动陪伴：系统通知（Android 系统通知）
- **重要事件通知**：
  - 孵化完成："壳在动！快来！"
  - 探索带回虫卵："我捡到了一个奇怪的蛋诶！"（**不提稀有度**，惊喜留到破壳）
  - 完全体达成："我长大啦！"
- **每日 1 条"今日想见你"轮换通知**（2026-11-05 新增）：随机 1 只宠物"特别想你"，互动得双倍星尘；可在设置中单独关闭；
- 通知文案全部以宠物第一人称口吻（现代萌系）。

### 2.6 日常循环（3~5 分钟一轮）
```
打开 App
  → 回到小窝：看宠物在干嘛 / 它回应你的离开时长与记忆
  → 自然手势互动：抚摸（划动）/ 喂食（拖拽食物）/ 逗玩（点击）
  → 安排宠物外出探索（成体解锁）
  → 收取上一次探索的成果（食物/虫卵/见闻故事）
  → 关闭 App，等宠物下次"找你"
```

### 2.7 交互方式：自然手势
| 动作 | 手势 | 宠物反馈 |
|---|---|---|
| 抚摸 | 手指在宠物身上划动 | 眯眼、呼噜声、身体跟随手指 |
| 喂食 | 从食物盘拖拽食物到宠物嘴边 | 张嘴、咀嚼动画、开心跳 |
| 逗玩 | 点击/戳宠物或玩具 | 追逐、歪头、叼玩具递给你 |
| 破壳 | 长按蛋并晃动 | 蛋壳裂纹、抖动、破壳而出 |

### 2.8 外出探索
- 成体及以上可派出探索，数小时后带回：
  - 食物（喂食经济来源之一）
  - 概率带回虫卵（虫卵可能孵化出稀有度更高的宠物，但蛋外观与时长完全一致，稀有度破壳才揭晓）
  - 见闻故事（回来"讲给你听"，喂给记忆系统）
- 探索期间该宠物不在小窝（离线惊喜感来源）。

### 2.9 食物经济（免费闭环）
- 来源：**探索带回 + 每日登录赠送**。
- 无商店、无付费，MVP 不含商业化。

### 2.10 图鉴与主宠切换
- 图鉴展示所有已获得宠物（含未孵化的卵）与收集进度。
- 同一时间只有**主宠**在 3D 小窝中；在图鉴中可任意切换出场宠物。
- 图鉴同时承担长期收集目标（最终 25 只完全体）。

### 2.11 场景与家园
- 单一温馨 3D 小窝/庭院，**纯背景不装扮**（无装扮系统）。

### 2.12 存档
- 首版**本地存档**（设备内）；云存档与账号体系随二期社交一并考虑。

### 2.13 桌面陪伴：Android 桌面小组件
- 宠物缩略形象 + 状态文案（如"阿绒在等你""团团去探险啦"）常驻手机桌面；
- 点击小组件进入 App；
- 数据来源：本地存档（小组件由 App 内状态推送更新，重要状态变化时刷新）；
- 悬浮窗实时宠物、动态壁纸为后续可选增强，MVP 不做。

### 2.14 稀有度系统（2026-11-05 新增）
- **四档**：普通 / 稀有 / 史诗 / 传说；
- **绑定种类**：稀有度固定绑定宠物种类，同一只宠物永远是同一档（同种不同稀有度的场景在规则上不存在）；
- 分配原则：每系 5 只 = 普通×2、稀有×1、史诗×1、传说×1；MVP 毛虫系 3 只：**团团=普通、长风=稀有、阿绒=史诗**（传说档随每系扩展至 5 只时开放）；
- **惊喜保护原则**：蛋的外观、纹路、孵化时长完全一致（4h），任何界面/通知都不得提前透露稀有度；稀有度在**破壳演出瞬间**揭晓——破壳 → 光效递进（普通无特效 / 稀有蓝光 / 史诗紫光 / 传说金光）→ 揭晓词；
- **稀有度零优势原则**（反歧视，见 2.17）：成长速度、互动反馈、行为动画、探索能力全部与稀有度无关，光效只存在于破壳瞬间与图鉴角标。

### 2.15 重复宠物处理：B+A 混合 + 节奏阀门（2026-11-05 新增）
- **B 阶段（图鉴未集齐）**：灵卵产出时只从**未拥有的种类**中抽取，每颗蛋必出新宠物，永不出现"重复的失望时刻"；
- **A 阶段（图鉴集齐后）**：探索仍带回蛋，孵出重复个体 → 温柔告别演出后转化为**星尘**（加速成长/兑换食物），重复变成收益；
- **节奏阀门**（防止加速凑齐、保期待感；2026-11-05 调参：4h 孵化 + 40% 掉率，目标每天保底孵 1~2 颗）：
  - 每日登录只送食物不送蛋；
  - 每 3 天登录保底 1 颗蛋（"神秘旅人的礼物"演出）；
  - 探索带回蛋概率约 **40%**；
  - **孵化位同时只能孵 1 颗，每颗孵化 4 小时**（适配上下班间隙操作节奏）；
  - 目标节奏：**每天保底孵化 1~2 颗蛋**；
  - 所有数值收在 GameConfig.ts，按留存数据调参；
- 期待感保障：B 阶段破壳仍有双重悬念（是哪一只 + 稀有度光效颜色）。

### 2.16 成长进度显示（2026-11-05 新增）
- **阶段即等级**：不做 1~50 级数字等级，成长阶段（卵→幼崽→成体→完全体）就是等级；
- 进度以可爱形式呈现：卵期为**蛋壳裂纹**填充，孵化后为**爪印/星星**填充，无冷冰冰的经验条数字；
- 与"行为化表达、无数值条"设计支柱一致。

### 2.17 反稀有度歧视机制（2026-11-05 新增）
- **问题**：稀有度会导致玩家只养稀有的、冷落普通档（且新手情感锚点团团=普通档，倒挂）；
- **原则**：稀有度只影响"相遇的仪式感"，不影响"相处的任何体验"；
- **四个机制**：
  1. **稀有度零优势**：成长/互动/动画/探索能力全部与稀有度无关（详见 2.14）；
  2. **今日想见你**：每天随机 1 只宠物"特别想你"（通知 + App 内提示），与它互动获得**双倍星尘**，软利益引导每日轮换培养；
  3. **系集齐奖励**：图鉴奖励按"某系全部宠物达到完全体"发放，普通档是必经之路；
  4. **失落可视化**：被冷落的宠物失落表达更明显，同理心驱动回归，永远可修复无惩罚。

## 3. MVP 范围（已确认）

**包含**：
1. 毛虫系 3 只，各完整四阶段成长线；
2. 行为化状态表达 + 记忆系统 + 见面回应；
3. 自然手势互动（抚摸/拖拽喂食/点击逗玩/长按破壳）；
4. 外出探索带回惊喜（食物/虫卵/见闻）；
5. 重要事件系统通知；
6. 图鉴 + 主宠切换；
7. 本地存档；
8. 食物经济（探索带回 + 每日赠送）；
9. 行为动画按成长阶段解锁；
10. Android 桌面小组件（宠物形象 + 状态文案 + 点击进 App）；
11. 稀有度系统（四档、绑定种类、破壳揭晓仪式、全程不剧透）；
12. 成长进度显示（阶段即等级 + 蛋壳裂纹/爪印星星可爱进度）；
13. 重复宠物处理（B+A：未集齐必出新、集齐后重复转星尘 + 蛋产出节奏阀门）；
14. 反稀有度歧视机制（稀有度零优势 + 今日想见你双倍星尘 + 系集齐奖励 + 失落可视化）。

**明确不做（二期及以后）**：
- 社交（拜访好友、异步互动）→ 二期，届时引入账号与云存档；
- 商业化（内购/广告）→ 暂不考虑；
- 家园装扮、多场景 → 暂不做；
- 悬浮窗实时宠物、动态壁纸 → 后续可选增强；
- 其余四系宠物 → 每期扩展一系（一期 15 只 → 最终 25 只）；
- 混世四猴隐藏池 → 终局内容，五虫集齐后开放；
- 微信小游戏版本 → Android 验证成功后移植。

## 4. 成功标准（MVP 验证什么）
1. 玩家是否产生"它在等我"的情感连接（次日留存）；
2. 3~5 分钟单次会话循环是否流畅自然；
3. 行为化状态 + 记忆回应是否比数值条更有陪伴感；
4. 通知召回是否有效且不打扰；
5. 桌面小组件是否提升"想起它"的频次（点击率）。
