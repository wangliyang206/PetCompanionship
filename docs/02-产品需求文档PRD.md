## 1. 产品概述

### 1.1 一句话定位
一款 3D 宠物陪伴休闲手游：玩家以"五虫"幻兽为伴，通过照顾、互动、探索与被记住，获得低成本、低负罪感的情感陪伴。

### 1.2 目标用户
- 独居年轻上班族/学生，时间碎片化。
- 需求：低成本的情感寄托；讨厌重度肝氪；喜欢"回来发现它在等我"的感觉。

### 1.3 发布平台
- **首版**：Android App（Cocos Creator 导出）。
- **后期**：微信小游戏/小程序（技术栈已预留该能力）。

### 1.4 设计支柱（所有功能以此为判据）
1. **陪伴感是真实的**——宠物有行为、有记忆、会主动出现；
2. **低负罪感**——忘记照顾没有数值惩罚，只有失落的行为表达；
3. **轻量短回合**——每次打开 3~5 分钟完成一轮循环，随来随走。

### 1.5 核心体验链（产品主轴，2026-11-05 确认）
```
寻蛋 → 孵化 → 抚育成长 → 解锁行为动画 → 图鉴 → 桌面小组件陪伴
```

## 2. 核心系统设计

### 2.1 宠物体系：五虫（世界观核心）
以《西游记》佛祖所言"五虫"为宠物分类根基：

| 系 | 古义 | 原型方向 | 一期 | 最终 |
|---|---|---|---|---|
| 毛虫 | 兽类 | 毛茸茸走兽 | ✅ 首发系（3 只分支） | 5 只 |
| 羽虫 | 禽鸟类 | 飞羽 | 3 只 | 5 只 |
| 鳞虫 | 鱼龙类 | 鳞光水族 | 3 只 | 5 只 |
| 介虫 | 龟甲类 | 甲壳 | 3 只 | 5 只 |
| 倮虫 | 裸体类（人为长） | 通灵幻兽 | 3 只 | 5 只 |

- 规模路线：一期 5 系 × 3 只 = 15 只 → 后期每系扩展至 5 只 = **最终 25 只**，图鉴收集驱动；
- **收集版图四层结构**（远期规划）：五虫 25 → +混世四猴 29 → +四灵（麟/凤/灵龟/神龙）33 → +四神兽（青龙/白虎/朱雀/玄武）37 → +上古四凶（混沌/穷奇/梼杌/饕餮，被陪伴感化的心象凶兽）41 → 山海经异兽**开放式图鉴池**（无上限，随版本新增）；每层解锁要求上一层全部完全体（详见《03-宠物形象设定文档.md》第 6 节）；
- **终局彩蛋【混世四猴】**：五虫 25 只全部完全体后解锁的隐藏独立池（4 只，不在五虫体系内，详见《03-宠物形象设定文档.md》第 5 节）——终局目标 + 反稀有度歧视的终极锚；
- MVP 只做毛虫系 3 只（详细形象见《03-宠物形象设定文档.md》）。

### 2.2 成长阶段（四阶段）
```
蛋/卵 → 幼崽 → 成体 → 完全体
```
| 阶段 | 时长（中等节奏） | 解锁内容 |
|---|---|---|
| 卵 | 按蛋类型（见 2.2.1） | 呼吸鼓动、左右轻摇、可抚摸加速；到点后**点一下即破壳**（不做长按门槛） |
| 幼崽 | 1~2 天 | 基础互动反馈（被摸/被喂/被逗），动作稚拙，反馈最强 |
| 成体 | 3~7 天 | 外出探索 + 新动作组 |
| 完全体 | — | 标志性大招动作，图鉴点亮 |

- **行为动画按成长阶段逐步解锁**，每个阶段都有"它学会新东西了"的惊喜（映射表见《03-宠物形象设定文档.md》）。

#### 2.2.1 孵化时长基准（存于 GameConfig.ts，可调参）
| 蛋类型 | 孵化时长 |
|---|---|
| 初始蛋（新手三选一） | 15 分钟（抚摸加速至最快约 5 分钟，首次会话内破壳） |
| 所有非初始虫卵（统一，**不暴露稀有度**） | 4 小时（日常抚摸可小幅加速，上下班间隙即可完成一轮） |

- 蛋的外观统一，仅随机纹路花样，**纹路与稀有度无关**——孵化前不能让玩家猜到成色；
- **稀有度在破壳演出瞬间揭晓**（见 2.15 稀有度系统）。

#### 2.2.3 孵化场景视觉要求（2026-11-06 新增，用户反馈驱动）
- **蛋必须一眼可读为"蛋"**：孵化中的蛋沿用三选一灵卵的绘制观感（神纹/光效/立体蛋形），禁止出现无纹理纯色圆——玩家不需要学习就该认出"这是一颗蛋在孵化"；
- **蛋孵化时位于软垫上**：蛋的渲染位置与窝内软垫对齐，破壳后幼崽位置不变；
- **软垫/窝必须可读**：有造型（垫状/窝状），不能是孤立的纯色色块；
- **蛋要"坐"在窝里**：窝的前唇必须压在蛋的下缘之上（遮挡关系），不能像摆在盘子中央的球；
- **画面里不允许出现无来源的色块**：3D 灰模、地面/后墙硬边一律要藏掉或融进背景（见 docs/06 D32）；
- **孵化倒计时条靠近蛋**呈现，与蛋形成视觉关联；
- 验收标准：无引导的新用户能自己说出"蛋在窝里孵化"。

#### 2.2.4 破壳演出（2026-11-06 明确，所有稀有度都有基础演出）
- **触发方式**：蛋到点后**点一下就破壳**，不做长按门槛（2026-11-06 用户反馈：长按破壳挫败感强、演出才是重点）；
- **基础演出（不分稀有度）**：点按 → 蛋抖动 → 白光一闪 + 蛋壳弹开 → 幼崽弹跳出场 + 星尘粒子 → 台词气泡"我出来啦！"；
- **稀有度光效**（叠加在基础演出之后）：普通无光效 / 稀有蓝光 / 史诗紫光 / 传说金光，从蛋位置迸发放射光，持续 ≥1.5 秒；
- **离线孵化补演出**：倒计时离线期间到点的蛋，打开 App 后保持待孵状态，由玩家点按触发完整演出——**禁止静默换模型**；
- **破壳后弹「恭喜获得」卡片**（2026-11-06 新增）：演出结束弹出卡片，内容为「恭喜获得新伙伴」+ 物种名 + 稀有度标签 + 系别标签 + 一句初见台词 + "它是你收养的第 N 位伙伴"；稀有度色做绶带与描边，物种主题色做系徽；轻触任意处关闭，关闭后宠物才说第一句问候；卡片同样是纯 Graphics（无贴图）；
- **孵化后宠物必须立即可见**：幼崽模型以物种主题色清晰呈现于软垫上，与互动反馈（抚摸/喂食/逗玩的动作回应）构成"它真的出生了"的时刻。

#### 2.2.2 第一个蛋：新手三选一认领仪式
1. 首次启动 → 空窝轻引导；
2. 三枚灵卵**从五系中随机抽取**（不同系各一枚，蛋壳纹路不同）**三选一**；
3. 拖拽放到窝内软垫 → 孵化倒计时开始；
4. 等待中引导摸蛋加速（首次互动教学）；
5. 三选一只决定"第一只"，未获得的宠物后续仍可通过探索/每日赠送获得；
6. MVP 降级：仅实装毛虫系时从毛虫系 3 只随机展示，逻辑按"随机抽系"实现。

- **互动加速成长**：抚摸/喂食/逗玩积累"陪伴值"，缩短成长等待。
- 完全体后宠物继续陪伴，收集下一只是长期动力。

### 2.3 状态系统：行为化表达（无数值条惩罚）
- 宠物没有可见的数值条，也**不会因为被忽略而死亡或严重惩罚**。
- 状态通过行为表达：
  - 状态好：主动蹭你、叼玩具给你、蹦跳、眯眼呼噜；
  - 状态失落：蹲坐无精打采、慢半拍回应、抬头看你又低头；
  - 回应"你很久没来"："你去哪儿了呀，我一直蹲在这里等你……"
- 重新照顾后数分钟内行为回暖，**永远可以修复关系**。

### 2.4 记忆系统
- 宠物记住关键事件：距上次上线的时长、喂过什么、玩过什么、探索带回了什么。
- 见面时主动提及（现代萌系口语）：
  - 离线 3 天："你三天没来啦，我把小饼干都留到过期了呜。"
  - 记住偏好："今天又是小鱼干！我就知道你记得我爱吃这个。"

### 2.5 主动陪伴：系统通知（Android 系统通知）
- **重要事件通知**：
  - 孵化完成："壳在动！快来！"
  - 探索带回虫卵："我捡到了一个奇怪的蛋诶！"（**不提稀有度**，惊喜留到破壳）
  - 完全体达成："我长大啦！"
- **每日 1 条"今日想见你"轮换通知**（2026-11-05 新增）：随机 1 只宠物"特别想你"，互动得双倍星尘；可在设置中单独关闭；
- 通知文案全部以宠物第一人称口吻（现代萌系）。

### 2.6 日常循环（3~5 分钟一轮）
```
打开 App
  → 回到小窝：看宠物在干嘛 / 它回应你的离开时长与记忆
  → 自然手势互动：抚摸（划动）/ 喂食（拖拽食物）/ 逗玩（点击）
  → 安排宠物外出探索（成体解锁）
  → 收取上一次探索的成果（食物/虫卵/见闻故事）
  → 关闭 App，等宠物下次"找你"
```

### 2.7 交互方式：自然手势
| 动作 | 手势 | 宠物反馈 |
|---|---|---|
| 抚摸 | 手指在宠物身上划动 | 眯眼、呼噜声、身体跟随手指 |
| 喂食 | 从食物盘拖拽食物到宠物嘴边 | 张嘴、咀嚼动画、开心跳 |
| 逗玩 | 点击/戳宠物或玩具 | 追逐、歪头、叼玩具递给你 |
| 拖动宠物 | 按住宠物本体拖动（拖源为宠物，与拖食物不冲突） | 见 2.7.1 |
| 破壳 | 点按蛋 | 抖动、白光、蛋壳弹开、幼崽出场、恭喜卡片 |

#### 2.7.1 拖动宠物本体（完整拖拽 + 情绪反应）
- **拖起瞬间**：四脚悬空小扑腾 + 惊讶表情（耳朵/尾巴竖起）；
- **拖动中**：身体随手指轻微摆动，眼神跟着"看"手指方向；
- **放下落地**：落地小弹跳 + 打滚起身；
- **位置情绪反应**（把拖拽变成逗宠方式）：
  - 放回软垫/窝 → 满足地蜷起来；
  - 放到食物盘 → 兴奋扑向食物；
  - 放到玩具堆 → 自动叼起玩具玩；
  - 放到窝外角落 → 委屈回望你，慢慢踱回来（不惩罚，低负罪感原则）；
- 手势区分规则：**拖源是宠物本体 = 拖宠物；拖源是食物盘 = 拖食物**，两者不冲突。

#### 2.7.2 自主溜达（心情驱动自由漫游）
- 宠物在小窝内**自主漫游**：散步 → 闻闻玩具 → 窝边发呆 → 找角落打盹，循环随机组合；
- **漫游行为由当前心情驱动**（与行为化状态一致）：
  - 开心 → 满场小跑、蹦跳；
  - 平静 → 慢悠悠踱步、东闻闻西看看；
  - 失落 → 蹲在角落、背对你、偶尔叹气式小动作；
  - 期待（你刚上线）→ 跑到窝门口迎你；
- **可打断性**：任何漫游状态下被抚摸/喂食/逗玩，立即停下进入对应互动回应——互动优先级永远最高；
- 漫游目标点由小窝场景预置锚点（软垫/食盆/玩具堆/窗边/角落）+ 随机游走生成。

### 2.8 外出探索
- 成体及以上解锁探索（幼崽不能出门；首次解锁时有引导教学）。

#### 2.8.1 派出方式：拖到门口
- 玩家**把宠物拖到小窝门口**（门口/小背包锚点），宠物兴奋地背上小包跑出画面——与"拖动宠物本体"机制（2.7.1）无缝衔接，无需额外按钮；
- 拖到门口后弹出**两档选择**：**短途（~2 小时，收益减半）** / **远征（~8 小时，全额收益）**，适配上下班间隙与睡前两种场景。

#### 2.8.2 收益与召回
- 归来带回（远征基准，短途按 0.5 倍折算）：
  - 食物（80% 概率，1~3 份，喂食经济来源之一）
  - 虫卵（40% 概率；蛋外观与时长完全一致，稀有度破壳才揭晓）
  - 见闻故事（必得，回来"讲给你听"，喂给记忆系统）
- **中途召回**：允许召回，按实际外出时长折算收益（时间太短可能空手而归），宠物回来表达"我还没玩够呢"——给玩家控制权但不鼓励频繁使用；
- 探索期间该宠物不在小窝（离线惊喜感来源）；通知在派出时注册（"我回来啦！好像带了点什么给你诶！"，不剧透掉落）。

### 2.9 星尘经济（2026-11-05 补全定义，数值可调参）

**星尘 = 宠物的心意凝成的星光**，游戏内唯一软性资源，无付费能力、无稀缺焦虑。

**用途（MVP 2 个）**：
| 用途 | 规则 |
|---|---|
| 加速成长 | 消耗星尘缩短当前孵化/成长等待：10 星尘 = -30 分钟 |
| 兑换食物 | 食物不足时兜底：5 星尘 = 1 份食物 |

**获取（4 条途径）**：
| 途径 | 数值 |
|---|---|
| 日常互动 | 每次抚摸/喂食/逗玩 +1，每日上限 20（防刷） |
| 今日想见你 | 与当日被选中宠物互动双倍（+2/次） |
| 重复孵化转化 | 每只重复宠物 +20（A 阶段） |
| 里程碑奖励 | 完全体 +30 / 系集齐 +100 / 图鉴满览大额 |

- 平衡校验：日均产出约 25~35 星尘，全程零等待一只宠物约需 60~100 星尘——轻度玩家自然攒、积极玩家够花；
- 无商业化，星尘永远不可用人民币购买。

### 2.10 食物经济（免费闭环）
- 来源：**探索带回 + 每日登录赠送**。
- 无商店、无付费，MVP 不含商业化。

### 2.11 图鉴与主宠切换
- 图鉴展示所有已获得宠物（含未孵化的卵）与收集进度。
- 同一时间只有**主宠**在 3D 小窝中；在图鉴中可任意切换出场宠物。
- 图鉴同时承担长期收集目标（最终 25 只完全体）。

#### 2.11.1 图鉴详情页（2026-11-06 新增）
- 点击任意格子进入**详情页**，内容自上而下：
  1. **宠物 3D 形象**（当前成长阶段模型，可旋转查看）；
  2. **名字 + 稀有度角标 + 系归属**（如"长风 · 稀有🔵 · 毛虫系"）；
  3. **性格小传**（一句话介绍，文案来源 = 《03-宠物形象设定文档》各宠物的性格设定，如"嘴硬心软的垂耳兔，其实比谁都想被摸摸"）；
  4. **系世界观一句话**（如"毛虫——兽类，周天之内五虫之一"）；
  5. **专属彩蛋描述**：完全体彩蛋预览，**完全体达成前显示"？？？"**（达成后点亮，给完全体追加一个"值得养到头"的理由）；
  6. 该宠物的**记忆摘要**（与这只宠物共同的重要事件，来自记忆系统，如"你们已相伴 12 天"）；
  7. 操作区：**设为主宠**按钮。
- **未解锁展示规则**：未拥有的格子显示**黑色剪影**（可见轮廓、不露配色）+ 系归属提示（"毛虫系·？？"），勾起收集欲但不剧透具体是谁；详情页对未解锁宠物只显示剪影 + 系世界观一句话，名字/性格/彩蛋均隐藏。

### 2.12 场景与家园
- 单一温馨 3D 小窝/庭院，**纯背景不装扮**（无装扮系统）。

### 2.13 存档
- 首版**本地存档**（设备内）；云存档与账号体系随二期社交一并考虑。

### 2.14 桌面陪伴：Android 桌面小组件
- 宠物缩略形象 + 状态文案（如"阿绒在等你""团团去探险啦"）常驻手机桌面；
- 点击小组件进入 App；
- 数据来源：本地存档（小组件由 App 内状态推送更新，重要状态变化时刷新）；
- 悬浮窗实时宠物、动态壁纸为后续可选增强，MVP 不做。

### 2.15 稀有度系统（2026-11-05 新增）
- **四档**：普通 / 稀有 / 史诗 / 传说；
- **绑定种类**：稀有度固定绑定宠物种类，同一只宠物永远是同一档（同种不同稀有度的场景在规则上不存在）；
- 分配原则：每系 5 只 = 普通×2、稀有×1、史诗×1、传说×1；MVP 毛虫系 3 只：**团团=普通、长风=稀有、阿绒=史诗**（传说档随每系扩展至 5 只时开放）；
- **惊喜保护原则**：蛋的外观、纹路、孵化时长完全一致（4h），任何界面/通知都不得提前透露稀有度；稀有度在**破壳演出瞬间**揭晓——破壳 → 光效递进（普通无特效 / 稀有蓝光 / 史诗紫光 / 传说金光）→ 揭晓词；
- **稀有度零优势原则**（反歧视，见 2.17）：成长速度、互动反馈、行为动画、探索能力全部与稀有度无关，光效只存在于破壳瞬间与图鉴角标。

### 2.16 重复宠物处理：B+A 混合 + 节奏阀门（2026-11-05 新增）
- **B 阶段（图鉴未集齐）**：灵卵产出时只从**未拥有的种类**中抽取，每颗蛋必出新宠物，永不出现"重复的失望时刻"；
- **A 阶段（图鉴集齐后）**：探索仍带回蛋，孵出重复个体 → 温柔告别演出后转化为**星尘**（加速成长/兑换食物），重复变成收益；
- **节奏阀门**（防止加速凑齐、保期待感；2026-11-05 调参：4h 孵化 + 40% 掉率，目标每天保底孵 1~2 颗）：
  - 每日登录只送食物不送蛋；
  - 每 3 天登录保底 1 颗蛋（"神秘旅人的礼物"演出）；
  - 探索带回蛋概率约 **40%**；
  - **孵化位同时只能孵 1 颗，每颗孵化 4 小时**（适配上下班间隙操作节奏）；
  - 目标节奏：**每天保底孵化 1~2 颗蛋**；
  - 所有数值收在 GameConfig.ts，按留存数据调参；
- 期待感保障：B 阶段破壳仍有双重悬念（是哪一只 + 稀有度光效颜色）。

### 2.17 成长进度显示（2026-11-05 新增）
- **阶段即等级**：不做 1~50 级数字等级，成长阶段（卵→幼崽→成体→完全体）就是等级；
- 进度以可爱形式呈现：卵期为**蛋壳裂纹**填充，孵化后为**爪印/星星**填充，无冷冰冰的经验条数字；
- 与"行为化表达、无数值条"设计支柱一致。

### 2.18 反稀有度歧视机制（2026-11-05 新增）
- **问题**：稀有度会导致玩家只养稀有的、冷落普通档（且新手情感锚点团团=普通档，倒挂）；
- **原则**：稀有度只影响"相遇的仪式感"，不影响"相处的任何体验"；
- **四个机制**：
  1. **稀有度零优势**：成长/互动/动画/探索能力全部与稀有度无关（详见 2.15）；
  2. **今日想见你**：每天随机 1 只宠物"特别想你"（通知 + App 内提示），与它互动获得**双倍星尘**，软利益引导每日轮换培养；
  3. **系集齐奖励**：图鉴奖励按"某系全部宠物达到完全体"发放，普通档是必经之路；
  4. **失落可视化**：被冷落的宠物失落表达更明显，同理心驱动回归，永远可修复无惩罚。

## 3. MVP 范围（已确认）

**包含**：
1. 毛虫系 3 只，各完整四阶段成长线；
2. 行为化状态表达 + 记忆系统 + 见面回应；
3. 自然手势互动（抚摸/拖拽喂食/点击逗玩/点按破壳）；
4. 外出探索带回惊喜（食物/虫卵/见闻）；
5. 重要事件系统通知；
6. 图鉴 + 主宠切换；
7. 本地存档；
8. 食物经济（探索带回 + 每日赠送）；
9. 行为动画按成长阶段解锁；
10. Android 桌面小组件（宠物形象 + 状态文案 + 点击进 App）；
11. 稀有度系统（四档、绑定种类、破壳揭晓仪式、全程不剧透）；
12. 成长进度显示（阶段即等级 + 蛋壳裂纹/爪印星星可爱进度）；
13. 重复宠物处理（B+A：未集齐必出新、集齐后重复转星尘 + 蛋产出节奏阀门）；
14. 反稀有度歧视机制（稀有度零优势 + 今日想见你双倍星尘 + 系集齐奖励 + 失落可视化）。

**明确不做（二期及以后）**：
- 社交（拜访好友、异步互动）→ 二期，届时引入账号与云存档；
- 商业化（内购/广告）→ 暂不考虑；
- 家园装扮、多场景 → 暂不做；
- 悬浮窗实时宠物、动态壁纸 → 后续可选增强；
- 其余四系宠物 → 每期扩展一系（一期 15 只 → 最终 25 只）；
- 混世四猴隐藏池 → 终局内容，五虫集齐后开放；
- 微信小游戏版本 → Android 验证成功后移植。

## 4. 成功标准（MVP 验证什么）
1. 玩家是否产生"它在等我"的情感连接（次日留存）；
2. 3~5 分钟单次会话循环是否流畅自然；
3. 行为化状态 + 记忆回应是否比数值条更有陪伴感；
4. 通知召回是否有效且不打扰；
5. 桌面小组件是否提升"想起它"的频次（点击率）。
