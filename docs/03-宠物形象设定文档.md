## 1. 世界观：五虫缘起

上古分生灵为五虫：羽虫翔于天，毛虫走于野，鳞虫游于渊，介虫伏于地，倮虫灵于万物。传说每只虫的元神都住在一枚"灵卵"里，卵随陪伴的温度而醒——**你陪它越久，它长得越像"它自己"**。

游戏中的宠物是五虫后裔的小小幻兽，被人间玩家的心意唤醒，住进玩家的小窝。而五虫之外，另有四猴"不在周天之内"——那是陪伴的终点才能相遇的传奇（见第 5 节）。

## 2. 总纲

| 倮虫 | 通灵幻兽 | 神秘、灵性 | 果冻/咕噜/知知 | +汤圆/月见 |

- 稀有度四档（普通/稀有/史诗/传说，绑定种类），每系 5 只 = 普通×2、稀有×1、史诗×1、传说×1；
- **惊喜保护**：蛋外观/纹路/孵化时长完全一致，稀有度只在破壳演出时揭晓（普通无特效→稀有蓝光→史诗紫光→传说金光）；
- 四阶段：**卵 → 幼崽 → 成体 → 完全体**；
- 初始蛋：新手三选一，三枚卵从五系随机抽取（MVP 从已实装的毛虫系随机展示）。

## 3. 毛虫系（走兽）｜治愈、暖

> 3D 基调（2026-11-05 定案：绒毛治愈风）：绒毛质感可爱风（像真实毛绒玩具），非扁平卡通；大眼睛、圆润轮廓；幼崽更圆更小，完全体加入主题特征的华丽化；手游用绒毛贴图方案控制性能。概念预览图见 docs/previews/。

### 3.1 团团（圆滚滚）｜稀有度：普通 ⚪
- **原型/性格/主题色**：仓鼠×毛团；嘴馋、爱囤、心大；杏黄
- **卵**：圆滚滚带绒纹的蛋，随呼吸轻轻鼓动
- **幼崽「团籽」**：一颗会走路的小毛球，摔倒是常态
- **成体「团团」**：长出小短手，捧着食物塞颊囊
- **完全体「囤宝·团团」**：颊囊能掏出探索时藏的小惊喜
- **标志性**：开心原地滚成球；失落瘫成一摊饼

### 3.2 长风（长耳朵）｜稀有度：稀有 🔵
- **原型/性格/主题色**：垂耳兔×风；好奇、胆小、嘴硬心软；天青
- **卵**：耳形纹路的纺锤形蛋，会左右摇
- **幼崽「风芽」**：耳朵耷拉遮住眼睛，走路撞墙
- **成体「长风」**：耳朵支起来了，能听到你进门的声音
- **完全体「逐风·长风」**：耳朵可御风，探索距离最远
- **标志性**：开心耳朵转圈圈；被戳先炸毛再蹭回来

### 3.3 阿绒（大尾巴）｜稀有度：史诗 🟣
- **原型/性格/主题色**：小狐狸×云朵尾巴；黏人、爱撒娇、戏精；霞粉
- **卵**：云纹圆蛋，摸起来"暖暖的"
- **幼崽「绒球」**：尾巴比人大，被自己尾巴绊倒
- **成体「阿绒」**：用尾巴当被子裹住你（文案）
- **完全体「拥云·阿绒」**：尾巴变成小窝，其他宠物来访都爱挤（二期社交伏笔）
- **标志性**：开心尾巴摇成残影；失落裹进尾巴只露眼睛

### 3.4 扎扎（小刺球）｜稀有度：普通 ⚪ ｜一期后扩展
- **原型/性格/主题色**：小刺猬；慢热、谨慎、其实超黏人；栗棕
- **卵**：带软刺纹路的椭圆蛋，被摸会缩一下
- **幼崽「刺球」**：遇到动静就卷成球，露出一双眼睛偷看
- **成体「扎扎」**：敢摊开身子了，刺变成软软的绒刺
- **完全体「披甲·扎扎」**：背上刺开花结果（果子可摘下来喂别的宠物）
- **标志性**：开心时刺立起来一颤一颤；失落卷成球滚到角落

### 3.5 元宝（小貔貅）｜稀有度：传说 🟡 ｜一期后扩展
- **原型/性格/主题色**：貔貅幼崽；大方、护主、自带福相；金褐
- **卵**：金纹圆蛋，据说"见者有福"（文案）
- **幼崽「金团」**：额头有云纹，走路一步三晃
- **成体「元宝」**：长出小犄角，尾巴卷成铜钱形
- **完全体「纳福·元宝」**：探索带回的东西永远比别人多一件（能力彩蛋：探索加成）
- **标志性**：开心时打滚撒金光粒子（纯演出，无数值）；失落蹲在存钱罐旁边叹气

## 4. 其余四系（概念设定）

> 每只一行式：卵 / 幼崽 / 成体 / 完全体 + 性格。一期每系先实装标 ⭐ 的 3 只。

### 4.1 羽虫系（禽鸟）｜轻盈、自由
- **咕咪**（普通⚪）⭐ 小文鸟：嗑瓜子、爱模仿你说话的调调（模仿彩蛋）
  卵：斑点小蛋会啄壳 / 幼崽：绒毛圆球扑腾 / 成体：尾羽分叉会站肩膀 / 完全体「知音·咕咪」：能完整学一句你的口头禅
- **嘎黄**（普通⚪） 小黄鸭：走路外八、洗澡狂魔
  卵：黄色蛋摇起来"嘎" / 幼崽：泡在小水盆里不肯出来 / 成体：羽翼丰满带水花特效 / 完全体「踏浪·嘎黄」：身后跟着一小队鸭宝宝
- **风铃**（稀有🔵）⭐ 小蜂鸟：三分钟热度但速度惊人
  卵：彩虹光泽小蛋悬空微浮 / 幼崽：悬停不稳画"之"字 / 成体：可悬停采蜜送花 / 完全体「无影·风铃」：探索时间减半（最快归来）
- **照夜**（史诗🟣） 小猫头鹰：白天打瞌睡、晚上精神——**熬夜搭子**
  卵：星空纹蛋夜晚微微发光 / 幼崽：站不稳栽头 / 成体：夜间陪伴模式（转脑袋） / 完全体「守夜·照夜」：夜晚打开 App 它已为你亮起小灯（夜间专属待机）
- **焰焰**（传说🟡） 朱雀雏鸟：高傲但会偷偷给玩家暖手
  卵：焰纹蛋有温度 / 幼崽：头顶呆毛是火苗 / 成体：尾羽如流火 / 完全体「浴火·焰焰」：完全体演出—火焰中重生，羽色焕新

### 4.2 鳞虫系（水族）｜梦幻、优雅
- **泡泡**（普通⚪）⭐ 小金鱼：记性差但快乐，转圈都能转出笑声
  卵：透明泡纹蛋 / 幼崽：吐泡泡当球玩 / 成体：尾鳍如纱 / 完全体「云霞·泡泡」：尾鳍展开如晚霞
- **糯糯**（普通⚪） 六角恐龙：永远在微笑的呆萌脸
  卵：粉色软纹蛋 / 幼崽：六根腮毛一抖一抖 / 成体：腮毛变成小花状 / 完全体「春水·糯糯」：身边常有樱花瓣漂过（纯演出）
- **鲤鲤**（稀有🔵）⭐ 小锦鲤：转发好运本鲤——获得时图鉴彩蛋"今天适合许愿"
  卵：红白锦纹蛋 / 幼崽：尾巴短像团棉花 / 成体：锦纹渐显 / 完全体「跃门·鲤鲤」：完全体演出—跃过小龙门，鳞片金光一闪
- **灯灯**（史诗🟣） 灯笼鱼：自带小夜灯，怕黑玩家的抱枕
  卵：蛋会一闪一闪 / 幼崽：头灯忽明忽暗 / 成体：灯光稳定暖黄 / 完全体「长明·灯灯」：夜晚模式光线照亮整个小窝
- **云吞**（传说🟡） 小白龙：白云做的身子，《西游记》白龙马同源
  卵：云纹蛋在雾气里 / 幼崽：云朵里探出龙头 / 成体：腾云绕窝一圈 / 完全体「行云·云吞」：探索归来踏雨云而至，带回的见闻总是特别长

### 4.3 介虫系（甲壳）｜憨厚、安稳
- **壳壳**（普通⚪）⭐ 小乌龟：慢吞吞哲学大师，"急什么呀"
  卵：绿纹硬壳蛋敲一敲会回敲 / 幼崽：翻身要三分钟 / 成体：壳纹长出青苔小花 / 完全体「千岁·壳壳」：壳上开出一个小花园
- **螺螺**（普通⚪） 小蜗牛：最慢但最专一，走过的路有亮晶晶痕迹
  卵：螺旋纹蛋 / 幼崽：壳比身子大 / 成体：壳上长蘑菇装饰 / 完全体「星轨·螺螺」：爬过的痕迹连起来是星图
- **铠铠**（稀有🔵）⭐ 小寄居蟹：爱捡东西换"新家"，每次探索可能带回新壳
  卵：捡了个瓶盖当窝的蛋 / 幼崽：换壳强迫症 / 成体：壳收藏家 / 完全体「百宅·铠铠」：图鉴可切换它收藏的任意壳（外观彩蛋）
- **钳钳**（史诗🟣） 小招潮蟹：戏精，横着走也要走出气场
  卵：蛋被双钳抱得紧紧的 / 幼崽：钳子比身子大挥不动 / 成体：挥钳子打招呼 / 完全体「横行·钳钳」：开心时横着走一整圈
- **武武**（传说🟡） 玄武幼崽：北方位神兽，背着小蛇朋友一起住
  卵：玄色龟甲纹双联蛋 / 幼崽：龟蛇俩小只挤一个壳 / 成体：小蛇偶尔探头 / 完全体「镇北·武武」：小窝得它镇守，风吹草动它先知道（见闻加成彩蛋）

### 4.4 倮虫系（通灵幻兽）｜神秘、灵性
> 古义"倮虫以人为长"——最通灵性的一支，形象走"无毛无鳞的灵气体"方向。
- **果冻**（普通⚪）⭐ 小果冻灵：Q 弹半透明，情绪写在晃动频率上
  卵：果冻质感蛋会"duang" / 幼崽：走路一弹一弹 / 成体：能变成小方块坐好 / 完全体「琉璃·果冻」：阳光下全身折射彩虹
- **汤圆**（普通⚪） 小团子灵：白白软软，怕烫怕冷爱过节
  卵：糯米粉质感圆蛋 / 幼崽：滚来滚去沾了一身"芝麻"斑点 / 成体：会包"迷你汤圆"送你 / 完全体「团圆·汤圆」：传统节日恰逢完全体会穿上小新衣（节日彩蛋）
- **咕噜**（稀有🔵）⭐ 小水滴灵：会变成一滩水打盹，被戳会溅你一脸
  卵：水滴形蛋里能看到小水涡 / 幼崽：走路"哗啦"声 / 成体：可凝成各种形状逗你 / 完全体「甘霖·咕噜」：情绪共鸣—你失落时它会变成一小朵雨云陪你
- **月见**（史诗🟣） 小月光灵：只在月光下现出全身，白天是半透明影子
  卵：月纹蛋昼淡夜亮 / 幼崽：像个小月亮影子 / 成体：月牙环身 / 完全体「满月·月见」：满月之夜全身绽放银辉（真实月相彩蛋）
- **知知**（传说🟡） 小白泽：通晓万物的神兽幼崽，**能提醒你忘记的事**（记忆系统联动彩蛋）
  卵：蛋上浮现过你在 App 里留下的痕迹 / 幼崽：额头知纹未开 / 成体：能"说"出你上次忘了收的探索成果 / 完全体「全知·知知」：图鉴详情页多了它的注解（图鉴查询加持）

## 5. 终局：混世四猴【隐藏独立池】｜全传说 🟡

- **解锁条件**：五虫 25 只全部完全体 → 仪式演出"五虫朝拜" → 如来开启**混世试炼**任务链；
- **获取规则（每章四选一，四章全拿，最终 4 只集齐）**：
  1. 任务链共 4 章，每章开始时从**尚未获得的猴中任选其一**挑战；
  2. 每章完成 → 如来赐下该猴的**灵石卵**（终局特殊蛋，孵化 24 小时，仪式节奏）；
  3. 灵石卵孵化 → 养成至完全体 → 下一章；
  4. 四章完成 → 四猴集齐，图鉴 29/29 满览，终局达成；
- 世界观："四猴混世，不入十类之种"——五虫是周天之内，四猴是周天之外；
- 定位：终局收集目标 + 反稀有度歧视终极锚。

| 猴 | 原著神通 | 形象与彩蛋 |
|---|---|---|
| 灵明石猴 | 通变化，识天时，知地利，移星换斗 | 石缝中诞生的金光小猴，完全体可"移"小窝里的一块石头当玩具 |
| 赤尻马猴 | 晓阴阳，会人事，善出入，避死延生 | 红臀马面小猴，见你会作揖行礼（最懂人事） |
| 通臂猿猴 | 拿日月，缩千山，谙休咎，乾坤摩弄 | 白臂长猿小猴，把玩日月（大招：双手托起小太阳/月亮） |
| 六耳猕猴 | 善聆音，能察理，知前后，万物皆明 | 六耳小猴，**能复述你上次说过的话**（记忆系统神通彩蛋） |

- **重叠调和（重要设定）**：焰焰（朱雀雏鸟）、武武（玄武幼崽）、云吞（小白龙）为"四象/神兽留在人间的幼影"，元宝（貔貅）埋白虎伏笔（貔貅为虎子之说）；四神兽实装时对应幼影触发"感应"羁绊彩蛋（如朱雀降临当日焰焰绕窝飞三圈）——老宠物获得新剧情，不报废；
- **四凶核心设定：凶兽不是被打败的，是被"陪"好的**——四凶是被辜负的负面心象（饕餮=没人喂过、穷奇=没人摸过、梼杌=没人等过、混沌=没人看过它）；玩家持续照顾逐阶段"卸下凶相"，完全体露出反差萌真身；图鉴条目写法：凶相描述划掉 + 旁边手写小字"其实它只是想要人陪"；
- **山海经开放池**：知知（白泽）为引路者（"最早来到人间的山海异兽"）；不设图鉴终点，随版本持续上新；新异兽复用五系骨骼/动画管线，边际成本低；
- 每层解锁要求上一层全部完全体，与"培养而非囤积"价值观一致；
- 节奏评估：按当前阀门，四灵约 2~3 个月、四神兽约 4~5 个月、凶兽章约 5~6 个月触及，其后开放池承担长线运营。

## 7. 通用视觉与动画规范

### 7.1 视觉
- 色调：奶油色系暖色 + 每只一只主题色；
- 小窝：温馨木质庭院一角，纯背景，柔和光照，突出宠物；

### 7.2 行为动画清单（行为化状态的核心资产）
| 类别 | 动画 |
|---|---|
| 待机 | 左右看、舔毛/理鳞/擦壳、小踱步、打哈欠 |
| 开心 | 蹦跳、原地转圈、各自标志性动作 |
| 失落 | 瘫坐、抬头看你又低头、慢半拍回应 |

### 7.3 行为动画解锁映射（按成长阶段）⭐核心链"解锁行为动画"
| 阶段 | 解锁动画 | 惊喜点 |
|---|---|---|
| 卵期 | 呼吸鼓动、左右轻摇、被抚摸时加速颤动 | "它在回应我的手！" |
| 幼崽 | 基础互动：眯眼呼噜（被摸）、张嘴咀嚼（被喂）、歪头（被点）、蹦跳、踱步、打哈欠 | 破壳演出："它学会跟我玩了！" |
| 成体 | 新动作组：各自成体新动作、探索出发/归来演出、蹭镜头 | "它会自己出门探险了！" |
| 完全体 | 标志性大招动作（见各只设定）+ 专属待机彩蛋 | "它长成了独一无二的样子！" |

- 解锁演出：每次阶段进阶伴随"解锁新动作"小演出（笨拙尝试 → 成功 → 求夸奖）。

### 7.4 文案风格指南（现代萌系）
- 全部第一人称"我"，称呼玩家不设固定称谓（自然口语）；
- 常用语气词：啦、呜、诶、嘛、哦；
- 允许小小的"戏精式抱怨"，禁止指责性文案（低负罪感原则）；
- 通知文案 = 宠物口吻 + 事件钩子，示例：
  - 孵化："壳、壳在动！！快来快来！"
  - 探索带回蛋："我捡到了一个奇怪的蛋诶！它暖暖的诶！"（不得提前透露稀有度）
  - 完全体："我长大啦！以后的以后也要在一起哦。"
